# Portfolio Web — Kruthika Naidu

Welcome to my personal portfolio website! 🌐
Built with React + Vite, this portfolio showcases my projects, skills, and work in full-stack development and AI-driven solutions.

## Project Structure

- `public/` — static files such as assets and images
- `src/` — main React app code and components
- `index.html` — app entry point
- `package.json` — dependencies and scripts
- `vite.config.js` — Vite configuration
- `eslint.config.js` — lint rules

## Main Features

- Built with **React + Vite**
- Responsive UI design
- Full-stack and AI project showcases
- Modern portfolio layout for personal branding

## Run Locally

1. Install dependencies:
```bash
npm install
```

2. Start the dev server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
